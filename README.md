# Turrini Realistic Drive v6

Android native driving prototype:
- C++17
- Bullet Physics
- OpenGL ES 3.0
- 4-wheel raycast vehicle
- suspension, steering, braking, acceleration
- procedural mountain terrain
- mobile touch controls
- arm64-v8a
- GitHub Actions APK build

## Important
The current visual vehicle is procedural. Replace it later with the project's GLB/GLTF vehicle model and connect wheel nodes to the physics wheel transforms.

## Build
Push to GitHub and run Actions -> Build Turrini Realistic Android.
